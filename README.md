# **團體線上點餐系统 (Group Ordering System)**

一個無須後端伺服器的輕量化團體線上點餐系統，支援多品項規格配置、購物車計算、廚房餐點數量自動彙總以及 AI 菜單圖片辨識功能。非常適合辦公室、學校或社團團購午餐與下午茶。

## **✨ 核心特色**

* 🍔 **預設丹丹漢堡菜單**：內建完整的熱門菜單資料，即開即用。  
* ⚙️ **客製化選項與加價購**：支援多種口味、套餐附餐選擇、飲料容量升級與炸雞部位備註。  
* 🧾 **即時購物車計算**：個人點餐金額自動加總與細項說明。  
* 👥 **團體訂單彙總**：即時統計所有人點的餐點總額與個別細項。  
* 🍳 **廚房對單模式**：自動將所有人點的套餐拆解為「單品元件」（如總共幾份炸雞、飲料容量），方便向店家統一下單。  
* 📷 **AI 菜單圖片辨識**：支援上傳新菜單照片，自動辨識生成新的點餐選項。  
* 📱 **響應式 UI 設計**：完美適應手機與電腦螢幕。

## **🛠 本地開發與執行**

不需要安裝 Node.js 或建置工具，直接在電腦雙擊開啟 index.html 即可在瀏覽器中運行與測試。
